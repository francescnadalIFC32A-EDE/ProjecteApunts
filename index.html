1. HTML

HTML és el llenguatge que s'utilitza per crear l'estructura d'una pàgina web. Permet afegir títols, paràgrafs, imatges, enllaços i llistes.

Exemple:

<h1>Hola!</h1>
<p>Aquesta és una pàgina web.</p>

Etiquetes bàsiques

  • <title>: títol que apareix a la pestanya del navegador i als cercadors.
  • <h1> a <h6>: títols i subtítols.
  • <p>: paràgrafs o blocs de text.
  • <br>: força un salt de línia.
  • &nbsp;: espai en blanc que no es trenca entre línies.
<h1>Títol 1</h1>
<p>Aquest és un paràgraf.</p>
<p>Aquest text es dividirà<br>en dues línies.</p>
<p>Aquesta és la frase "12&nbsp;homes".</p>

Atributs HTML

Els atributs afegeixen informació extra a les etiquetes per modificar-ne el comportament o l'aparença. Sempre van dins l'etiqueta d'obertura amb el format nom="valor".

  • id: identificador únic de l'element.
  • class: classe per aplicar estils a diversos elements.
  • style: estils CSS directament a l'element.
  • title: informació addicional en passar el ratolí per sobre.
  • src, alt, href: propis d'imatges i enllaços.
<h1 id="titol">Títol 1</h1>
<h2 class="important">Títol 2</h2>
<h3 style="color: blue; text-align: center;">Títol 3</h3>
<h4 title="Informació addicional">Títol 4</h4>

Comentaris

Els comentaris són notes dins el codi que no es veuen a la pàgina i no afecten el rendiment. Serveixen per documentar el codi, descriure seccions o desactivar codi temporalment.

<!-- Aquesta secció és el capçal de la pàgina -->
<!-- TODO: afegir un formulari de contacte -->

Bones pràctiques

  • Mantenir-los clars i concisos.
  • Evitar-ne massa: només on calgui.
  • No deixar comentaris innecessaris en producció.

Inserció d'imatges

L'etiqueta <img> insereix imatges. No té etiqueta de tancament (és auto-tancada).

  • src: font o camí de la imatge (relatiu o URL completa).
  • alt: text alternatiu per a lectors de pantalla, SEO i quan la imatge no carrega.
  • width i height: amplada i alçada (píxels o percentatges).
<img src="imatge.jpg" alt="Descripció de la imatge" width="400" height="300">
<img src="imatge.jpg" alt="Imatge adaptada" style="width: 100%;">

Bones pràctiques

  • Posar sempre l'atribut alt.
  • No inserir imatges molt grans sense reduir-ne la mida.
  • En disseny responsiu, usar percentatges en lloc de píxels.

2. CSS

CSS serveix per canviar l'aparença d'una pàgina web, com ara els colors, les mides de lletra i la distribució dels elements.

Exemple:

body {
    font-family: Arial, sans-serif;
    color: black;
}

3. XML

XML és un llenguatge de marques que permet guardar i organitzar dades amb etiquetes pròpies.

Exemple:

<llibre>
    <titol>El meu llibre</titol>
    <autor>Anna</autor>
</llibre>

4. JSON

JSON és un format de text que s'utilitza per intercanviar dades entre aplicacions.

Exemple:

{
    "nom": "Anna",
    "edat": 18
}

5. HTTP

HTTP és un protocol que permet que el navegador i el servidor es comuniquin per carregar pàgines i altres recursos web.

  • GET: demana informació.
  • POST: envia informació.
  • 404: el recurs no s'ha trobat.

6. Accessibilitat web

L'accessibilitat web consisteix a crear pàgines que puguin utilitzar persones amb diferents capacitats.

  • Utilitzar títols ordenats.
  • Afegir text alternatiu a les imatges importants.
  • Fer que els enllaços tinguin noms clars.
  • Permetre navegar amb el teclat.

7. SVG (ampliació)

SVG és un format de gràfics vectorials que es pot ampliar sense perdre qualitat. S'utilitza per a icones, logotips i dibuixos.

Exemple:

<svg width="100" height="100">
    <circle cx="50" cy="50" r="40" fill="blue" />
</svg>

8. APIs web (ampliació)

Una API permet que dos programes es comuniquin i intercanviïn dades. Moltes APIs web utilitzen HTTP i envien dades en format JSON.

Relació entre els conceptes

HTML crea l'estructura de la pàgina i CSS en canvia l'aparença. HTTP permet carregar els recursos. JSON i XML serveixen per organitzar dades. SVG permet mostrar gràfics, i les APIs faciliten l'intercanvi d'informació. L'accessibilitat s'ha de tenir en compte en tot el projecte.
