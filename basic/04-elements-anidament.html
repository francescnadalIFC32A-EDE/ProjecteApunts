Elements HTML i anidament

  • Etiqueta (tag): part que marca l'inici o el final d'un component, entre < >. Ex.: <p>, </p>.
  • Element: etiqueta d'obertura + contingut + etiqueta de tancament. Ex.: <p>Aquest és un paràgraf.</p>.
  • Anidament: col·locar un element dins d'un altre. La primera etiqueta que s'obre és l'última que es tanca.
<body>
  <p>Text amb <strong>element anidat</strong>.</p>
</body>
