Introducció a HTML

HTML (HyperText Markup Language) és el llenguatge de marques per crear pàgines web. Defineix l'estructura de la pàgina amb etiquetes que el navegador interpreta per mostrar el contingut.

Breu història

  • Creat per Tim Berners-Lee el 1991.
  • HTML 2.0 (1995): primer estàndard oficial.
  • HTML5 (2014): última versió, amb suport per a vídeo, àudio i gràfics.
